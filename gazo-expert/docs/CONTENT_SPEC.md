# コンテンツ仕様（用語辞書 & 問題）

対象: CG-ARTS 画像処理エンジニア検定 エキスパート（公式テキスト『ディジタル画像処理［改訂第二版］』準拠、マークシート選択式、80分・大問10、70点合格）。

## カテゴリID
| id | 分野 |
|---|---|
| cam | ディジタル画像の撮影（カメラモデル・光学系・撮像素子・標本化量子化） |
| color | 画像の性質と色空間（人間の視覚・表色系・画質評価） |
| tone | 画素ごとの濃淡変換（トーンカーブ・ヒストグラム・画像間演算） |
| filter | 領域に基づく濃淡変換（空間フィルタリング） |
| freq | 周波数領域におけるフィルタリング（フーリエ変換等） |
| restore | 画像の復元と生成（劣化モデル・逆/ウィーナーフィルタ・合成・超解像・HDR等） |
| geo | 幾何学的変換（アフィン・射影・補間・画像合成） |
| binary | 2値画像処理（2値化・連結性・ラベリング・モルフォロジー・距離変換・細線化） |
| region | 領域処理（領域分割・輪郭/形状特徴・テクスチャ） |
| detect | パターン・図形・特徴の検出とマッチング |
| recog | パターン認識・機械学習・深層学習 |
| d3 | 3次元復元・空間情報・光学的解析 |
| motion | 動画像処理 |
| code | 画像符号化・圧縮・ファイル形式 |
| sys | 画像処理システム（ハードウェア・ソフトウェア・表示デバイス） |
| ip | 知的財産権（著作権・産業財産権・肖像権等） |

## 用語ファイル `content/terms/<cat>.json` — JSON配列
```json
{
  "id": "filter-median",          // 英小文字・数字・ハイフン。必ず "<cat>-" で始める。一意
  "term": "メディアンフィルタ",
  "reading": "めでぃあんふぃるた",  // ひらがな（英字略語は読みをカタカナ可）
  "en": "median filter",
  "cat": "filter",
  "short": "近傍画素の中央値で置換する非線形平滑化フィルタ",   // 60字以内
  "def": "詳しい定義と仕組み（200〜450字）",
  "points": ["試験で問われやすい要点", "..."],             // 2〜5個
  "formula": "任意。プレーンテキストの式 例: g(i,j)=median{f(i+m,j+n)}",
  "history": "任意だが推奨。誰が/いつ/なぜ生まれたか、背景、発展",
  "year": 1974,                    // 任意。提案年など（数値）
  "confuse": "任意。紛らわしい概念との違い",
  "related": ["filter-average", "ごま塩ノイズ"]   // 同カテゴリはid、他カテゴリは日本語の用語名で可（ビルド時に解決）
}
```

## 問題ファイル `content/questions/<cat>.json` — JSON配列
```json
{
  "id": "filter-q001",
  "cat": "filter",
  "style": "text|figure|calc|term2def|def2term|fill|combo",
  "lead": "任意。大問のリード文（複数問で共有してよい）",
  "stem": "問題文",
  "figure": { ... },               // 任意。下記
  "choices": ["ア…", "イ…", "ウ…", "エ…"],   // 4〜6個。文字列 or {"text":"...","figure":{...}}
  "answer": 0,                     // 0始まりの正解index
  "explain": "解説：正解の理由と、各誤答がなぜ誤りか",
  "terms": ["filter-median", "ごま塩ノイズ"],   // 関連用語（id or 用語名）。解説から辞書へ飛ぶリンクになる
  "level": 2                       // 1=基礎 2=標準 3=難
}
```
- 選択肢の先頭に「ア.」等の記号は付けない（アプリが付与）。
- 「適切なものを選べ」「誤っているものを選べ」の両方を混ぜる。誤り選択型は stem で明示。
- fill（穴埋め）: stem に （a）（b） の空欄、choices は「a: X, b: Y」形式の組合せ。
- combo（組合せ）: 「正しいものの組合せ」型。

### figure の種類
- `{"type":"grid","data":[[0,128],[255,64]],"max":255,"values":true,"caption":"入力画像"}` 濃淡画素グリッド（2値はmax:1）
- `{"type":"matrix","data":[[1,0,2],[0,1,3],[0,0,1]],"label":"A ="}` 行列/カーネル表示
- `{"type":"table","head":["…"],"rows":[["…"]]}`
- `{"type":"svg","svg":"<svg viewBox='0 0 200 120' xmlns='http://www.w3.org/2000/svg'>…</svg>"}` 図解（シングルクォート推奨、200〜320幅程度、文字は font-size 10〜14）
- 複数図は `"figures":[...]`
