# 画像処理エキスパート特訓 — 調査・設計メモ

## 1. 調査：試験の前提
- 主催：CG-ARTS（画像情報教育振興協会）。公式テキストは『ディジタル画像処理［改訂第二版］』。2021年以降はこのテキスト全体から出題される。
- 形式：マークシート、**大問10題・80分、100点満点中70点で合格**（エキスパート）。2025年前期の合格率は34.4%（受験者450人）。
- 第1問は CG-ARTS の各検定に共通する**知的財産権**（著作権の事例問題）。
- 合格者の体験記で多く出るとされる形式：
  - 元画像にフィルタをかけた**結果の画像を選ぶ**、結果画像から**使われたフィルタを当てる**（計算問題では定義が問題文に書いてあることが多い）
  - **射影変換・アフィン変換の結果画像**を選ぶ、合成変換と等価な計算
  - **フーリエスペクトルの画像を選ぶ**
  - 用語・手法の説明文を選ぶ問題、リード文の空欄(a)〜(d)を埋める問題

## 2. 分野（カテゴリ）設計
公式の出題範囲（撮影／画像の性質と色空間／濃淡変換とフィルタリング／復元と生成／幾何学的変換／2値画像・領域処理／パターン・図形・特徴の検出とマッチング・認識／深層学習／動画像処理・空間情報・光学的解析／符号化／知的財産権）を16カテゴリに分けた（`CONTENT_SPEC.md`）。
アプリの「推定スコア」と「おまかせ」で新しい問題を選ぶときは、各カテゴリに配点の目安で重みを付けている（`tools/build.mjs` の weights）。

## 3. 辞書（用語）設計
用語1つにつき：短い定義／詳しい定義／試験のポイント／式／**歴史・いきさつ（年）**／紛らわしい概念との違い／**関連用語（他分野へのリンク）**。
- 解説文や定義文に出てくる用語は**自動でリンク**になり、タップすると辞書が**ボトムシート**で開く（問題の画面から離れない）。シートの中でさらにリンクをたどれ、←で戻れる。
- 年がある用語は「歴史年表」に時系列で並ぶ。

## 4. 出題形式の設計
| 形式 | 実装 |
|---|---|
| 文章の4択（適切／不適切を選ぶ） | 静的問題 `style:text` |
| リード文の空欄補充・正しい組合せ | `fill` / `combo`（共通の `lead` を表示） |
| 計算問題 | 静的 `calc`、**自動生成**（毎回数値が変わる） |
| 図を見て答える（画素グリッド・カーネル・行列・SVG図解） | `figure` |
| **画像処理の結果画像を選ぶ** | **自動生成エンジン**が実際に画素計算した画像を選択肢にする |
| 用語→説明／説明→用語 | 辞書から4択を自動で作る（両方向） |

自動生成（`www/js/gen.js`）の29種：フィルタ結果の選択／使われたフィルタの判定／3×3フィルタの出力値計算／トーンカーブ↔出力画像／処理後のヒストグラム／ヒストグラム平坦化の計算／アフィン変換の結果／変換行列の判定／合成変換の行列／最近傍・双線形補間／モルフォロジー演算／連結成分数・オイラー数／距離尺度／縞画像↔フーリエスペクトル／周波数領域フィルタ（理想・ガウシアン、リンギング）／平行ステレオの奥行きと距離分解能／透視投影／薄レンズ／F値と露出／標本化定理／データ量・ビットレート／エントロピー・ハフマン符号／輝度・CMY・補色／PSNR／ハフ変換(ρ,θ)／SSD・SAD・ZNCC／CNNの出力サイズとパラメータ数／適合率・再現率・F値・IoU。

## 5. 記憶管理（分かる／分からない／忘れかけ）
- 間隔反復（ライトナー方式を圧縮した間隔：0, 10分, 6時間, 1日, 2日, 4日, 7日）。1週間で終わる短期決戦に合わせて間隔を短くしている。
- 正解したら「**確信あり**／**たまたま・あやふや**」の自己申告。あやふやは昇格させない（まぐれ当たりを習得と数えない）。
- 「わからない」ボタンで当て推量せずに解説へ進める（不正解として記録）。
- 状態：未学習／苦手／学習中／習得／**要復習**（習得したが復習期限が過ぎた）／**忘れかけ**（一度習得した後に間違えた）。
- 問題を間違えると、その問題に関連する用語も苦手側に下がる。用語カードで取り違えた相手の用語も復習対象になる。
- セッション中に間違えた問題・用語は、数問後に（カードの場合は逆方向で）もう一度出る。

## 6. モード
おまかせ（期限切れ＋苦手＋未習＋生成問題＋用語カード）／弱点・忘れかけ集中／模擬試験（10大問・80分・最後に採点、大問別の得点）／分野別／画像ドリル／用語カード／辞書／進捗／歴史年表。

## 7. 配布
- Web（HTML/JS、外部ライブラリなし、オフラインで動く）を Capacitor で Android アプリにする。
- GitHub Actions がプッシュのたびに APK をビルドし、Release `gazo-expert-latest` に置く。署名鍵は固定なので、上書きインストールしても学習記録は消えない。
